# TSDP Portal Logo Assets

Place your high-resolution PNG or SVG logo files directly in this directory:

1. `neca-logo.png` - Nigeria Employers' Consultative Association (NECA) logo
2. `itf-logo.png` - Industrial Training Fund (ITF) logo
3. `shamzbridge-logo.png` - ShamzBridge Consult logo
4. `tsdp-logo.png` - (Optional) Technical Skills Development Project logo

These logos are referenced directly in:
- Header navigation (`src/components/Navbar.jsx`)
- Login screens (`StudentLogin.jsx`, `CoachLogin.jsx`, `AdminLogin.jsx`)
- Printable reports (`ViewReports.jsx`)

If the files are not yet present, the portal automatically displays elegant SVG fallback badges with the exact brand colors!
